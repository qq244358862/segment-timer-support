常见问题

如何开始一次会话？

在计时页点击“新建会话”，设置总时长和阶段，按需选择项目、填写会话名称、备注和阶段名称，然后点击“开始”。

如何避免重复设置？

在新建会话页面使用“添加为模板”保存当前设置。之后可从“选择模板”快速套用，也可以重命名、调整或删除模板。

如何调整历史会话所属项目？

打开 History 中的会话详情，点击项目入口，即可添加到项目、移动到其他项目或移出当前项目。

为什么 AI 分析不可用？

请检查设置中的 API Key、Base URL 和模型。AI 分析需要网络连接及有效的第三方 AI 服务凭证；计时、模板、项目和历史记录不依赖 AI。

数据保存在哪里？

核心应用数据保存在设备本地。只有当你主动请求 AI 分析并确认发送时，相关会话内容才会发送到你配置的 AI 服务。

联系支持

如问题仍未解决，请通过 GitHub 提交支持请求，并说明设备型号、iOS 版本、应用版本和复现步骤。请勿在公开问题中粘贴 API Key 或其他敏感信息。

English Support

How do I start a session?

Tap New Session, configure the total duration and phases, optionally select a project and add session details, then tap Start.

How do templates work?

Use Add as Template to save the current session setup. You can later apply, rename, edit, or delete templates from Choose Template.

How do I change a session's project?

Open a session from History and use the project control to add it to a project, move it, or remove it from its current project.

Why is AI analysis unavailable?

Check the API key, Base URL, and model in Settings. AI analysis requires an internet connection and valid credentials for the third-party AI service you configure. All core timing features work without AI.

Where is my data stored?

Core app data is stored locally on your device. Relevant session content is sent to your configured AI service only when you request analysis and confirm the transfer.

Contact

For assistance, open a support request. Include your device model, iOS version, app version, and steps to reproduce. Never include your API key.
