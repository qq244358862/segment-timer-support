隐私政策

段落计时器以本地保存为基础，不要求注册账号。你可以在不使用 AI 功能的情况下完整使用计时、模板、项目和历史记录功能。

1. 本地保存的数据

会话名称、备注、计划与实际时长、阶段名称、项目、模板、历史记录、应用语言及相关设置保存在你的设备上。应用不运营用户账户服务器，也不使用这些数据进行广告追踪。

2. AI 分析与第三方服务

AI 分析是可选且由用户手动触发的功能。首次使用前，应用会说明将发送的数据并请求你的同意。你主动同意并请求分析后，应用可能向你配置的第三方 AI 服务发送：

  • 会话或项目的题目与目的；
  • 备注、阶段名称和工作流程背景；
  • 计划与实际的总时长和分段时长。

第三方服务将依据其自身条款和隐私政策处理这些数据。请仅使用你信任的服务地址。

3. API Key

你填写的 API Key 保存在设备的系统安全存储中，并仅用于向你配置的 AI 服务验证请求。开发者无法通过本应用服务器读取该 Key。请勿与他人分享你的 Key。

4. 用户选择与撤回

你可以不配置 API Key，核心功能仍可正常使用。你也可以在设置中撤销 AI 数据发送同意；更换 AI 服务地址后，应用会再次请求确认。设备上的应用数据可通过删除应用清除，但 iOS 系统安全存储中的凭证可能受系统 Keychain 行为影响，建议先在设置中清空 API Key。

5. 数据保留与删除

本地数据由你控制并保留在设备上。第三方 AI 服务对已发送内容的保留与删除规则由相应服务提供商决定。如需删除已发送的数据，请查阅该服务的隐私政策和账户管理选项。

6. 儿童隐私与政策更新

本应用并非专门面向儿童设计。政策发生重要变化时，本页面将更新内容和日期。

7. 联系我们

如对本政策有疑问，请通过支持页面提交请求。请勿公开提交 API Key 或敏感会话内容。

Privacy Policy — English

Local data

Segment Timer stores session names, notes, planned and actual durations, phase names, projects, templates, history, language, and related settings locally on your device. No account is required, and the app does not use this data for advertising tracking.

Optional AI analysis

AI analysis is optional and manually initiated. After you consent, session or project topics, notes, phase names, workflow context, and planned and actual timing may be sent to the third-party AI service you configure. That provider processes data under its own terms and privacy policy.

API keys

Your API key is stored in the device's secure system storage and is used only to authenticate requests to your configured AI service. The developer does not receive the key through an app-operated server.

Your choices

Core features work without an API key. You can revoke AI data-sharing consent in Settings. Changing the AI service address requires new consent. To remove a stored credential, clear the API key in Settings before deleting the app, because iOS Keychain behavior may preserve secure credentials.

Retention and deletion

You control locally stored app data. Retention and deletion of content sent to an AI provider are governed by that provider's policies and account controls.

Children and changes

The app is not specifically directed to children. Material changes to this policy will be reflected on this page with a new update date.

Contact

For privacy questions, open a support request. Do not include API keys or sensitive session content in public requests.
